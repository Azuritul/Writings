WWDC26で発表された「[What’s new in the Foundation Models framework](https://developer.apple.com/videos/play/wwdc2026/241/)」の動画をもとに、Foundation Models frameworkにどんな変化があったのかをまとめました。

## 変わったところ

全体像はこんな感じです。Foundation Models frameworkで扱えるモデルの範囲が広がりました。

| 変更点 | ざっくり何が変わったか |
|---|---|
| `LanguageModel` | Appleのモデル以外も同じ形で扱える |
| 画像入力 | テキストと画像を同じプロンプトに渡せる |
| PCC | より大きいタスクをPrivate Cloud Compute側で処理できる |
| Dynamic Profiles | セッション中にモデル、ツール、指示を切り替えられる |
| `fm` / Python SDK / Evaluations | 開発、検証、評価のための道具が増えた |

## オープンソース化と外部モデルへの対応

* **オープンソース化:** フレームワークのコアAPIがオープンソース化されます。Linuxサーバーを含め、Swiftが動作する環境であれば、どこでもこのフレームワークを用いたLLMの制御が可能になります。
* **モデル抽象化レイヤー:** `LanguageModel`プロトコルの導入により、Apple独自のモデルだけでなく、ローカル実行用の`CoreAI`や`MLX`、さらには**Google**や**Anthropic**が提供する外部のサーバーモデルを同じコードベースのまま統合・切り替えができるようになります。サードパーティのLLMと統合することも可能になります。

![モデル抽象化レイヤー](/images/article-what-is-new-in-foundation-models-wwdc2026/abstraction.png)

## オンデバイスモデルの進化

* **Vision（画像理解）機能のネイティブ統合**
  * インターネットにデータを送信せず、iPhoneやMacの内部だけで画像を解析できるようになりました。
  * テキストの指示と一緒に写真や画像データをAIに入力し、その画像について質問や指示を出すことが可能です。
  * 画像のサイズや縦横比（アスペクト比）はどんな形でもそのまま認識するため、事前の切り抜きなどの加工は不要です（※画像が大きいほど、消費するトークン量と処理の遅延が増加します）。
* **思考力（ロジック）とツール呼び出しの精度向上**
  * モデルが根本から作り直されたことで、「筋道を立てて考える能力」や「アプリ内の他の機能をAIが自分で判断して動かす能力（ツール呼び出し）」が向上しました。
* **端末の性能に応じた自動調整用のAPIを追加**
  * アプリ開発者が、いま動いている端末のハードウェア性能に合わせて処理を最適化できるよう、AIが扱える長文の限界値（コンテキストサイズ）を調べたり、文字数（トークン数）を事前にカウントしたりできる機能が追加されました。

## Private Cloud Compute（PCC）の提供

* **仕様:** ローカルモデルの処理能力を超えるタスク向けに、Appleの専用クラウド基盤で動作するPCC言語モデルが利用可能になります。32,000トークンのコンテキストウィンドウを持ちます。
* **推論（Reasoning）モード:** 応答の前にステップを踏んで思考する訓練が施されており、追加の計算リソースと引き換えに精度の高い回答を出力するオプション（Reasoning Level）が追加されます。
* **プライバシーとコスト:** 送信されたプロンプトは一切保存されず、外部の研究者による検証が可能です。新規ダウンロード数が200万未満の開発者であれば、開発者側のクラウドAPIコスト負担なしで利用できます。また、これによりwatchOS 27でも同フレームワークが動作可能になります。

## Dynamic Profiles（ダイナミックプロファイル）

* **コンテキスト管理の効率化:** 1つの言語モデルセッション内で、複数の異なるプロファイル（指示、ツール、使用モデルの構成）を宣言的に管理する新しいAPIです。
* **自動遷移:** アプリの状況変化（例：「データの分析」から「アイデアの生成」への移行など）に応じて、会話履歴を維持したまま、バックエンドで動く指示や使用モデル（オンデバイスからPCCへの切り替えなど）をフレームワーク側が自動でシームレスに遷移させます。

## 開発・評価用ツールの追加

* **OS内蔵ツール:** バーコードリーダーやOCR（光学文字認識）を行うVisionツール、および `Core Spotlight` を用いてデバイスのローカル環境だけで検索拡張生成を実装できる「ローカルRAG」ツールがネイティブで提供されます。
* **CLIと他言語対応:** Macのターミナルからモデルを直接呼び出せるコマンドラインツール`fm`、およびPython環境から直接オンデバイスモデルにアクセスしてスクリプトを構築できる「Foundation Models SDK for Python」が提供されます。

![fmコマンドラインツール](/images/article-what-is-new-in-foundation-models-wwdc2026/fm.png)

* **評価フレームワーク:** プロンプトの変更がモデルの出力精度に与える統計的な影響を計測・定量化するための「Evaluationsフレームワーク」が新たに提供されます。
